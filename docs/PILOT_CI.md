# Hosted pilot CI

`.github/workflows/pilot-release.yml` is the dedicated email-pilot gate for PRs, `main`/`lmc/v1` pushes and manual dispatch. It has read-only repository permission and no deployment step or external provider keys. Its verify job installs frozen dependencies, runs the build-configuration tests/telemetry coverage/full build/types/lint/static artifact checks and verifies the committed embed output before running `node scripts/pilot-ci.mjs`. Independent jobs require complete-history Gitleaks with the existing reviewed policy, strict Semgrep with the unchanged 30-second rule timeout, and `pnpm audit --prod --audit-level high`. The final pilot-release-gate requires every dependency job to succeed; failed or skipped jobs cannot yield a green release result.

## Actual database and test scope

The runner requires Linux/WSL and a local default Unix Docker daemon, refuses private checkout env files, and requires the admin build first. It creates new labelled PostgreSQL/pgvector and Redis containers bound only to randomly assigned loopback ports. Runtime-role URLs and strong distinct internal/test credentials are generated for that disposable database. Migrate/bootstrap run twice, followed by database/forced-RLS checks. Existing environment switches enable PostgreSQL, all Redis test opt-in variables and the real form integration; no application quota or test deadline is increased.

Every workspace test source, script test and LMC acceptance source comes from an independent Git file inventory (including nonignored pending source files for local work). Vitest receives every source filename explicitly. This avoids executing generated `dist` copies as a second test inventory; it does not remove or change any original test assertion. The default legacy agent-core command previously executed both its TypeScript source and generated JavaScript copies. Source-only counts are therefore intentionally different from those duplicated historical totals.

The strict JSON verifier requires all reported assertions to pass, no pending/skipped/todo tests, consistent counters and exact expected file equality. A missing integration env variable therefore fails rather than silently reducing coverage. It also rejects missing files even if Vitest reports success. Empty reports are allowed only when the independent source inventory is empty. The actual test scope includes all workspace suites, all root script tests, every LMC acceptance file, the original strict 88-table/238-API-method assertions and configured-page access checks. Production public auth/static HTTP coverage runs separately against the production build with pilot mode unset, not against a mocked router.

The HTTP acceptance instance is owned by this run, uses fake external providers and a private shared inbound fixture, and is stopped afterward. Anonymous read-only startup probes compile/readiness-check the app before timed cases; they provide no tenant identity/capability and never invoke auth/callback write endpoints. The original isolation timeout remains 120 seconds. The runner removes only its labelled containers/anonymous volumes and restores only the expected Next-generated dev type-path changes. Stop a separately running dev preview before local reproduction to avoid sharing Next's dev lock.

## Evidence and credentials

Raw stdout, stderr, auth URLs, JSON test details and test secrets stay in a mode-restricted temporary directory and are never uploaded. The artifact contains only completion/cleanup flags, source test-file names/counts and optional GitHub run identity metadata. It never exports raw failure messages, delivery capabilities, cookies, environment values or tenant rows. A self-reported GitHub context is not hosted-execution certification: inspect the actual workflow run and all four job conclusions before claiming the hosted gate passed.

For local reproduction after `pnpm install --frozen-lockfile`, `pnpm build`, type/lint and build-configuration checks, run `node scripts/pilot-ci.mjs`. Use PILOT_CI_SUMMARY_FILE only for a new absolute sanitized-summary destination; an existing summary is refused so a stale green result cannot survive a failed rerun. Real domain/DNS, Resend, Google consent and LLM credentials belong to PILOT_STAGING.md, not this CI environment.
